Sidebar UX and visual language

A warm paper conversation column inside Excel’s Fluent pane. One reading column, quiet chrome, evidence in cool blue, and exactly one accent for action. The diff card is a first-class surface, not a hidden menu.

Excel Agent · Office.js task pane 7 Nov 2026 Direction A — warm paper, Fluent bones Review: inline card · History: per workbook Frames are 1:1 CSS px at 380 px webview unless marked
01 · The grid is the canvas

The pane is a reading column.

It never tries to become a second spreadsheet. Citations are the only bridge back to the sheet, and they are always one click away.

02 · Paper, not chrome

Fluent geometry, editorial surface.

Segoe, 32 px controls, focus rectangles and 4 px spacing come from Fluent. Warm paper, serif run-ins and terracotta come from Claude.

03 · Review is the product

One gate per turn, not per cell.

Approval is cheap enough to use every time. The diff, the risks and the per-change selection all live in one card that survives a partial apply.

The language

Tokens are defined once and consumed by role. Hex values in the tables are the source; components never invent a colour.

Warm ramp for surface and text. Cool blue only for evidence. Terracotta only for action.

1 2 3 4 5
  1. 1Identity, not a banner. 44 px: file name (truncating), unsaved dot, then history / settings at 32 px targets; new chat joins them once there is a conversation. One pane is tied to one workbook, so the name earns its line.
  2. 2The greeting is a question. Set in the serif at 22/27. It never repeats the product name or shows a logo card.
  3. 3Prompts fill the composer; they never send. Labels name the sheet or the current selection, so the first click is specific and editable.
  4. 4The composer is the only input surface. 1 px control border at 3.3:1, 10 px radius, 32 px send. The model picker is one click from the message, not buried in Settings.
  5. 5One trust line. It says the truthful thing: history is local, writes need approval. It does not claim workbook content never leaves the machine — model calls do.

1 2 3 4 5
  1. 1Tool-derived status. “Reading Forecast!A1:H400 · step 2 of 3” comes from the tool call, not a separate model request. On completion it becomes “3 steps · 4.8 s”, collapsed.
  2. 2Citation chips are evidence, not links. 20 px, mono, cool #EEF3F6 fill, #3F6599 text (5.32:1). Only explicit citations become chips; cell-looking prose does not.
  3. 3Tables scroll inside their own frame. Four columns at 348 px; the transcript never scrolls sideways and the page never clips a numeric column.
  4. 4A real reading measure. 14/22 Segoe at 380 px is about 48 characters. The only serif in the transcript is the run-in heading; body copy stays sans.
  5. 5Stop is a first-class control. The send circle becomes an ink stop circle; Esc also stops. The composer stays editable so the next message can be typed while the turn ends.

1 2 3 4 5 6 7
  1. 1Shape before detail. “12 changes in 3 ranges” plus the risk badges survive collapsing, so the card can be triaged without reading every row.
  2. 2Per-change inclusion is first-class. Checkbox defaults on; applying a subset is a normal path, not an advanced toggle. “12 selected” updates live.
  3. 3Before → after, in mono. Formulas show their text; values show the cell’s displayed text, so the workbook’s locale and number format are preserved. Long formulas wrap, never truncate silently.
  4. 4Range chips navigate. Click selects the range in the grid. Hover does not move the selection; navigation is never a side effect of reading.
  5. 5Risk lives on the row. Overwrite and dangerous-function notes sit beside the change they belong to, not in a separate modal the user has to map back.
  6. 6One primary action. The footer carries the count, Discard and Apply. There is no second Apply in the composer and no per-row apply.
  7. 7The gate is explained. The composer is disabled with a reason and a way out. This is the classic “dead input”; the hint is what stops it feeling dead.

  1. 1Cause and remedy in one line. The alert names cell-edit mode, not the model. It never says “something went wrong”.
  2. 2Failed rows keep their diff and their checkbox. Nothing is silently dropped and nothing is marked applied that wasn’t. The row tint is redundant with the “Failed” text.

  4. 4Composer stays gated until the queue is resolved. Dismiss is the escape hatch: it keeps the failed changes pending in the background, not applied.

A full-height view, not a popover. This workbook first, all workbooks behind a segmented control, one destructive action in the footer.

  1. 1Scope is a two-state control. This workbook is the default; “All workbooks” is the escape hatch. The list never mixes files without saying so.
  2. 2Active is not just bold. A 2 px accent bar and a tinted row carry the state, so it survives grayscale and color-blind viewing.
  3. 3Rows answer “which chat?” Title, one-line preview, message count and the sheets touched. Rename/delete live in the row overflow, not in the footer.
  4. 4Delete all is in the footer, in danger text. It is not a red block competing with the list. The lock icon states where history lives.
  5. 5New chat is in the view header. It creates a session; it never deletes the current one. The old conversation remains in the list.

1 2 3 4
  1. 1260 px is a supported width, not an edge case. New chat leaves the header first; it lives in History. The file name truncates before the remaining icons do.
  2. 2Tables scroll with a right-edge fade. Columns keep their content width; the pane never squeezes a numeric column to fit. The scrollbar is visible on hover and keyboard focus.

1 2 3 4
  1. 1Health is a banner; a turn failure is a card. The banner sits under the header and never covers the transcript. It clears itself when the service returns.
  2. 2Say what did not happen. “Your workbook is unchanged” is the first reassurance. Then the likely cause and the next action, in that order.
  3. 3Retry is primary; details are secondary. Raw error text is one mono line, collapsed, available for a bug report but never shouted.
  4. 4The composer closes with a reason. History and the existing transcript remain navigable; the user can still read and copy while the gateway is down.
